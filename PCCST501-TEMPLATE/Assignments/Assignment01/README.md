# Assignment 1

## Title: How the Internet Delivers a Web Page

## Objective
To understand how the Internet delivers a web page by studying the roles of the TCP/IP protocol stack, DNS, HTTP, TCP, and the Client–Server architecture in web communication.

## Solution
The browser converts the website name into an IP address using DNS, establishes a TCP connection with the server, sends an HTTP request, receives the webpage as an HTTP response, and displays it to the user. TCP ensures reliable data transmission throughout the process.

## Output
Successfully explained the complete process of web page delivery, including the functions of the TCP/IP layers, DNS, HTTP, TCP, cookies, and the Client–Server communication model with a communication flow diagram.

## Conclusion
The Internet delivers web pages through the combined operation of DNS, TCP, HTTP, and the TCP/IP protocol stack. These technologies enable reliable, secure, and efficient communication between web browsers and servers, making everyday Internet services fast and accessible.
